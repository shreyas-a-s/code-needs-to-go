## A place to store some of the good code that I remove from my projects

I always put a lot of effort into writing code so that it works beautifully without any issues. Hence my mind forms a sort of bond with that code. There always comes a time when some of that code needs to be deleted from the project.

It maybe because I found out more efficient ways to achieve the same goals or just because the direction of the project shifted. Nevertheless, I feel bad deleting those lovely codes that I put a lot of effort into. Maybe I have FOMO, idk :)

Hence, instead of simply deleting the code, I move it over to this repo. Over the years, this became a place where I store the code snippets that I use maybe once a year, but the ones that I definitely will forget.
